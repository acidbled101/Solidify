Trajectory

The full t=1→0 sampling schedule. Sampling runs normally up to the branch point, where it forks: a straight reference path (identical to what a normal generation would produce) and an arced delta path (a random perturbation, refined by a few gradient steps under the DPO preference loss). Both are decoded and scored by the judge; the pipeline resumes from whichever one it actually preferred — so the path shown after the gate is never worse than the reference would have been.

Branches

One row per fork point (more than one only if "num branches" > 1 in the run config). Click a row to inspect that fork's candidates, score breakdown, gradient steps, and histograms in the panels below — they always show one branch at a time.

Score breakdown weighted terms: α·R_Detail − (β·L_OH + γ·L_Th + δ·L_Topo)

A detail reward (higher = more fine surface detail) minus penalties for overhangs, thin walls, and non-manifold/open topology. The judge's actual winner is decided by an unweighted comparison value (shown in the score line above each viewer pane), which can occasionally disagree with the weighted total plotted here — that disagreement is flagged with a trailing * when thickness scoring was skipped as unreliable for that mesh.

Gradient steps loss / detail proxy / latent RMS, per steering step

Loss is the DPO preference loss on the branch being steered — it should trend toward 0 if the step is doing what it was told to. Proxy is the differentiable detail-energy term actually being optimized: the only signal the gradient sees (overhang/thickness/topology have no gradient here and only act through which branch the judge preferred). RMS is how far the perturbation has moved from its start, against the dashed trust-region ceiling it is never allowed to cross.

Geometry distributions

Per-element distributions behind the selected candidate's score, binned server-side (never sent as raw per-face/per-vertex arrays). Detail energy: per-vertex Laplacian magnitude, higher means more fine detail. Overhang: per-face angle-to-gravity cosine — right of the marked line is past the critical overhang angle and unsupported. Wall thickness: per-ray sampled wall depth — left of the marked line is thinner than the minimum printable wall. Edge incidence: 1 = open/boundary edge (bad), 2 = normal manifold edge.
